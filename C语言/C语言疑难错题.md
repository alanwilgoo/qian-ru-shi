1.全局变量定义的位置是（B）

A、函数内部 B、所有函数外部 C、主函数内 D、复合语句内

在C语言中，全局变量（也叫外部变量）定义在**所有函数之外**，通常放在源文件的开头部分。

2.简述常量和变量的区别
**答：**

常量和变量都是程序中用于表示数据的基本形式。**常量**是在程序运行过程中其值**不能改变**的数据，例如整数常量 `10`、字符常量 `'A'` 等。**变量**是在程序运行过程中其值**可以改变**的数据。变量在使用前通常需要先定义，并具有变量名、数据类型和相应的存储空间。

3.只要循环里对全局变量进行了赋值或运算，它的值就会改变，而且改变后的值会保留下来，不会因为一次循环结束就自动恢复。

4.`return 0;` 的作用是**结束 `main` 函数，终止整个程序的运行**。它放在哪里，程序就在哪里结束。

---

### 如果放在循环里面会怎样？

假设把 `return 0;` 放进循环体中：

```
for(i = 0; i < 5; i++){
    printf("%d ", arr[i]);
    return 0;  // 第一次循环就结束程序了！
}
```

执行过程如下：

1. `i = 0`，打印 `arr[0]`，即输出 `2`
2. 紧接着执行 `return 0;`，**程序立即终止**
3. `i = 1, 2, 3, 4` 的循环**根本不会执行**

最终输出只有：`2`

### 放在循环外面会怎样？

c

编辑

```
for(i = 0; i < 5; i++){
    printf("%d ", arr[i]);

return 0;  // 循环全部执行完毕后，才结束程序
```

执行过程如下：

1. 循环正常执行 5 次，依次打印 `2 4 6 8 10`
2. 循环结束后，才执行 `return 0;`，程序正常终止

最终输出：`2 4 6 8 10`

## **统计1至100之间素数的个数**

#include <stdio.h>

int is_prime(int n)

{

    if (n < 2)

    {

        return 0;

    }

    for (int i = 2; i * i <= n; i++)

    {

        if (n % i == 0)               

        {

            return 0;

        }

    }

    return 1;

}

int main(void)

{

    int count = 0;

    for (int n = 1; n <= 100; n++)

    {

        if (is_prime(n))

        {

            count++;

        }

    }

    printf("%d\n", count);

    return 0;

}

**运行结果：**25。

**解析：**1不是素数。从2到100逐个判断，若在2至其平方根之间找到整除因子，该数就不是素数，否则计数加1。只需检查到平方根，是因为 n=a×b 时，至少有一个因数不大于 √n。本题范围内 i*i 不会溢出。

**核对要点：**排除1；包含2和100这两个边界；正确判断整除；最终素数个数为25。


## **自定义函数实现字符串拼接**

题目要求：不使用 strcat()。

#include <stdio.h>

char *my_strcat(char *dest, const char *src)

{

    char *p = dest;

    while (*p != '\0')

    {

        p++;

    }

    while (*src != '\0')

    {

        *p = *src;

        p++;

        src++;

    }

    *p = '\0';

    return dest;

}

int main(void)

{

    char a[100] = "Hello";

    const char *b = " world";

    my_strcat(a, b);

    printf("%s\n", a);

    return 0;

}

**运行结果：**Hello world。

**解析：**先找到 dest 中原有的字符串结束符，再从这个位置依次复制 src 中的字符，最后补上新的空字符 \0。返回值保留目标字符串的起始地址。

**使用前提：**dest 指向可写数组，容量至少为两个字符串长度之和再加1，且源和目标不重叠。本例 a[100] 容量足够；不能用指向字符串字面量的 char *a="Hello" 作为可写目标。

**核对要点：**找到目标串末尾；逐字符复制；补写结束符；目标空间足够；不调用 strcat()。
