# 嵌入式学习与面试笔记

个人嵌入式学习和面试复习资料，主要涵盖 C 语言、数据结构、Linux 文件 I/O，以及技术与人事面试问答。

## 内容导航

- **C 语言基础**：进制、数据类型、指针、结构体与常见易错题。阅读 [知识点](C语言/C语言知识点.md) 和 [疑难错题](C语言/C语言疑难错题.md)。
- **数据结构**：顺序表、栈与队列、排序，以及 Linux 内核双向链表。阅读 [基础与排序](数据结构/数据结构.md) 和 [链表笔记](数据结构/数据结构-链表.md)。
- **Linux 文件 I/O**：系统 I/O 与标准 I/O、文件读写、文件定位和 `ioctl`。阅读 [文件 I/O 笔记](文件IO/文件IO.md)。
- **嵌入式技术面试**：C/C++、Linux、网络通信、数据结构与硬件基础。阅读 [技术问答一](嵌入式面试笔记/面试技术问题汇总1/面试技术问题汇总1.md)、[技术问答二](嵌入式面试笔记/面试技术问题汇总2/面试技术问题汇总2.md) 和 [嵌入式八股文](嵌入式八股文篇.md)。
- **人事与表达练习**：自我介绍、职业规划、团队协作和情景问答。阅读 [面试情商问答](嵌入式面试笔记/面试情商问题汇总_问答版/面试情商问题汇总_问答版.md) 和 [人事面试 150 问](人事面试题150问_问答整理版.md)，后者按 12 个主题整理，并附自我介绍及优缺点范文。

笔记以 Markdown 为主，可在 Obsidian 中通过全文搜索和标题大纲复习。图片及原始文档保存在对应资料目录中。
