# 嵌入式学习笔记

个人整理的嵌入式相关学习笔记与练习记录，内容持续补充中。

## 目录

- `C语言/`：C 语言基础、知识点与易错题整理。
- `C++/`：C++ 学习资料目录，具体笔记待补充。
- `数据结构/`：线性表、链表、栈与队列、排序等内容。
- `文件IO/`：Linux 文件 I/O 与相关系统调用、标准 I/O 笔记。
- `硬件内容/`：三极管等硬件基础笔记、配图，以及 LCD 色块显示练习题。

## 学习范围

目前主要覆盖 C 语言基础、指针与数据结构、文件 I/O 和部分硬件基础；另设有 C++ 学习目录。LCD 练习题记录了显存映射与像素拷贝等要求。仓库以学习笔记和题目整理为主，不代表这些练习均已有完整实现。
